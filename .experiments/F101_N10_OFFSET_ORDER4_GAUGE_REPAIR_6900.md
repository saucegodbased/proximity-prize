## 1. The old failure is invariant across the affine lift fibre

For the fixed chamber


has rank 1590 and nullity 59.  The exact polynomial `J` map has rank 12 on
that kernel, so every solved RHS has a 47-dimensional homogeneous `C+J`
fibre.  The test retains that whole fibre; it does not inspect only the
canonical nullspace representative.

For `V=Y-QZ`, `V1=R-Q'Z`, write the complete grade-seven shell as

```text
T2 V1 V^2 Z^4 + H3 V^3 Z^4
+ E1 V1 V Z^5 + D2 V^2 Z^5
+ E0 V1 Z^6   + D1 V Z^6 + D0 Z^7 + H4 V^4 Z^3.
```

The old three-carrier form imposes

```text

```

The resulting exact linear system has rank/columns `(77,77)`.  Appending
any one of `F0,F1,F2` raises the rank by one, and appending all three also
raises it by one.  Hence none of the three RHS has an old-form
representative anywhere in its 47-dimensional affine fibre.

For comparison, the matched `Q` chamber has system rank/columns `(69,77)`
and all three RHS are feasible.
