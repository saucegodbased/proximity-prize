## 1. The theorem whose quantifiers control every composition claim


This quantifier mismatch is at least as important as the A57 rank defect. A

## 4. PML / CompPoly: narrow pivot, broad rabbit hole

### Narrow GO

Use the external PML checkout, or another fast PM-basis implementation, as a
research oracle for exactly one question:

```text
Does the exact structured F3 residue rho belong to the affine coset of the
83-row Lee--O'Sullivan module below the literal shifted-degree bound, with
[Y] fixed to B and the other boundary coefficients fixed as required?
```

The acceptable outputs are deliberately asymmetric:

- **RED:** a compact dual/remainder annihilating every legal zero-boundary
  Lee correction and pairing nontrivially with `rho`. Together with the
  specialization lemma identified above, this would falsify the necessary
  pure face and stop every Full187 F3 lift using this source.
- **GREEN:** explicit coefficient polynomials giving a legal preimage, plus
  a replay of every shifted degree, fixed coefficient, and contact identity.
  The witness then has to be compressed enough to verify in Lean and fit the
  submission envelope.

Patched CompPoly is valuable after such a result because its existing
soundness/completeness and row-span-preserving reduction theorems can support
the proof. PML itself is an external `/tmp` research checkout and is not an
allowed prebuilt submission dependency. A PML run is therefore evidence only
until reduced to a verifier-checkable certificate.

### STOP

Do not treat either package as a solution to the full `(Y,R,S,Z)` problem.

- CompPoly has no general approximant/syzygy-module constructor for the
  187-shape contact congruences.
- Its stock Lee operation returns a least nonzero row, not an element with a
  prescribed affine coefficient.
- Naively materializing the 83 high-degree power rows is already identified
  as memory-unsafe.
- The A57 obstruction is caused by tapered physical windows and cross-outer-Z
  coupling; bivariate row reduction cannot repair it.
- A full PML basis may be far larger than a useful proof certificate, and the
  library cannot be copied into the submission.

Thus PML/CompPoly is a useful **pure-face decision pivot**. It is a rabbit
hole if the goal silently expands to “discover the full reducer,” “formalize
PML,” or “infer four-packet DUAL4 from a least Lee row.”

## 6. Process changes to stop local-GREEN inflation

### 6.1 Require a composition header on every artifact

Every new note should begin with six machine-checkable fields:

```text
goal theorem and exact declaration name;
quantifiers: universal / target instance / finite control;
domain and direction data frozen or arbitrary;
source map: full / quotient / projection;
consumer implication supplied by an existing theorem;
first unproved outgoing key.
```

If any field is unknown, the result is not endpoint progress.

### 6.2 Replace the single word GREEN with scoped labels

Use labels such as:

```text
ENDPOINT_CHAIN_GREEN
UNIVERSAL_LEMMA_GREEN
TARGET_INSTANCE_GREEN
LOCAL_BLOCK_GREEN
PROJECTED_COVERAGE_GREEN
API_INTERFACE_GREEN
FINITE_CONTROL_GREEN.
```

Only the first two should change proof-completion estimates. In particular,
“no dual exists on this projection” is `PROJECTED_COVERAGE_GREEN`, not a
partial membership proof.

### 6.3 Maintain one theorem DAG and charge only closed cuts

The DAG in the executive verdict should live in one current file. A commit
gets positive compositional credit only if it closes a named edge or replaces
an open node by strictly smaller open nodes. Exact ranks that leave the same
edge open are useful research but score zero in the completion ledger.

The active-block cycle shows why: three impressive determinants suggested a
global formula, but the first broad symbolic test found A68, and the maximal
legal-prefix test found the structural A57 defect. Frontier falsification
should follow the first two local examples, not the tenth.

### 6.4 Use actual-RHS quotients before raw surjectivity projects

Raw surjectivity is a convenient sufficient condition, not the endpoint
claim. When it fails, immediately quotient the actual incoming operator by
the maximal legal image and test that much smaller map. Conversely, when raw
surjectivity is GREEN, still record which actual RHS/caller uses it. This
avoids both false pessimism at A57 and false optimism from large ambient
ranks.

### 6.5 Freeze long-run bytes and certificate exits

Before a long computation starts, record the exact script hash, command,
memory/time cap, expected GREEN certificate, and expected RED certificate.
Commit or copy the immutable run input before execution; do not edit the
running file. The full-shell F193 run began from a modified working-tree
script, but commit `608835b` subsequently recorded the executed-byte hash and
the exact result. That post-run repair should be a pre-run invariant in the
next long gate.

### 6.6 Make external computation prove something small

PML, LinBox, FLINT, and Python should emit a compact identity, preimage, or
dual, followed by an independent verifier. A multi-megabyte basis with only a
rank summary is not a submission asset. Set the certificate-size limit before
the run, not after a GREEN result.

### 6.7 Build the exact caller early

Create a non-production experimental theorem with conclusion
`TargetBadFamilyBound6900` and explicit holes for only:

```text
the universal high-degree four-packet theorem;
the producer-to-component/52-chart bridge;
the final union/allocation inequality.
```

This would make it impossible to call a fixed F3 instance, an abstract Schur
equivalence, or consumer arithmetic “nearly integrated.” Each either fills a
hole or it does not.

### 6.8 Resolve source-policy metadata before packaging claims

The outer repository `AGENTS.md` supplied to this work says 10 MiB and 80
minutes; `yukon-6900-work/AGENTS.md` says 16 MiB and four hours, while several
recent notes still cite the former values. The local `challenges.json` does
not contain the verifier `source:` limits needed to adjudicate the conflict.
Until the authoritative challenge manifest is checked, use the stricter
limits and do not report packaging readiness. This discrepancy does not
affect the mathematical audit, but it invalidates confident size/time claims.

## 7. Bottom line

The program has made real progress in identifying the correct modules and in
killing false extrapolations. Its positive theorem content is nevertheless
concentrated at the endpoint wrapper, the low-degree scalar split, abstract
linear-algebra/consumer interfaces, and a finite initial segment of one
Full187 reducer.

The current decisive gaps are independent:

```text
1. exact affine membership of the necessary pure F3 face;
2. the A57 actual-tail/cross-outer-Z quotient and the rest of Rlt13;
3. a universal four-packet/DUAL4 theorem, not one frozen instance;
4. a producer-to-component/52-chart caller proving TargetBadFamilyBound6900.
```

No number of F101 GREENS, scalar Euler projections, raw Hilbert margins, or
additional same-Z local determinants composes around those four cuts. The
right near-term strategy is therefore falsifier-first and interface-first:
freeze the full-shell RED, decide the full pure-face affine coset, test the
one-dimensional A57 quotient, and expose the exact bad-family caller before
undertaking another broad reducer or formalization project.
